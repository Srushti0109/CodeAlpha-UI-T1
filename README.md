📱 Task 1 – Wireframing & Low-Fidelity Design
📌 Project Overview
This project contains low-fidelity wireframes designed in Figma as part of Task 1.
The goal was to create the initial structure and layout for a mobile application/website concept.

👉 Prototype Link: View Wireframes in Figma (https://www.figma.com/proto/K4wgWPVMTiggFKHWstsS8m/T1?node-id=1-2&p=f&t=7sJLQpdNBxyX8dnk-1&scaling=scale-down&content-scaling=responsive&page-id=0%3A1)

🎯 Objectives
Develop wireframes for a mobile app or website (e.g., food delivery, e-commerce, or education platform).

Focus on user flow, navigation, and layout rather than visual styling.

Ensure clarity and usability in the design.

Submit wireframes using Figma.

🛠 Tools Used
Figma – for wireframing and interactive prototyping.

📂 Wireframe Structure
Homepage – Entry point with navigation options.

Category/Feature Pages – Showcases main functionality (e.g., product listing, food menu, or course modules).

Detail Page – Provides more information about a selected item.

Cart/Checkout/Enrollment Page – Demonstrates transaction flow.

Profile/Settings Page – User account management.
